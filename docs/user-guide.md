# User Guide

## Candidate

### Registration & Login
1. Visit the landing page and click **Get Started**
2. Select **I'm Looking for a Job** as your role
3. Fill in your name, email, and password
4. You'll be redirected to your candidate dashboard

### Profile Setup
1. Go to **Profile** from the sidebar
2. Fill in your headline, location, phone, and bio
3. Add your skills summary, experience years, and education
4. Add links to LinkedIn, GitHub, and portfolio
5. Click **Save Profile**

### Upload Resume
1. Go to **Resume** from the sidebar
2. Click **Upload Resume**
3. Select a PDF, DOCX, or TXT file (max 10MB)
4. Click **Parse** to extract structured data (optional, uses AI)
5. Set a resume as **Active** to attach it to applications

### Search & Apply for Jobs
1. Go to **Job Search** from the sidebar
2. Use filters: keyword, location, employment type, salary range, skills
3. Click on a job to view details
4. Click **Apply Now** and select your active resume
5. Optionally add a cover letter

### Save Jobs
1. Click the bookmark icon on any job card
2. View saved jobs under **Saved Jobs** in the sidebar
3. Remove saved jobs by clicking the bookmark icon again

### Job Alerts
1. Go to **Job Alerts** from the sidebar
2. Click **Create Alert**
3. Enter keywords, location, and employment type preferences
4. Alerts will show matching new jobs in your notifications

### Track Applications
1. Go to **Applications** from the sidebar
2. View all your applications with status (Applied, Shortlisted, etc.)
3. Click on an application to see full details and timeline
4. You can **Withdraw** an application if needed

### View Interviews
1. Go to **Interviews** from the sidebar
2. View upcoming interviews with date, time, and type
3. See interview details including location/link

### AI Features
- **Job Match**: On any job detail page, view your AI match score (0-100)
- **Skill Gap**: See which skills you're missing for a job
- **Career Insights**: Get personalized career recommendations
- **Resume Analysis**: Get AI suggestions to improve your resume
- **Recommendations**: View AI-curated job matches on your dashboard

### Notifications
1. Click the bell icon in the top bar
2. View notifications for application updates, interviews, and alerts
3. Mark individual notifications or all as read
4. Configure notification preferences under **Notifications > Preferences**

### Analytics
1. Go to **Analytics** from the sidebar
2. View your application stats, status distribution, and trends
3. Track your job search progress over time

## Recruiter

### Login
1. Visit the login page
2. Enter your recruiter email and password
3. You'll see the recruiter dashboard

### Profile Setup
1. Go to **Profile** from the sidebar
2. Fill in company name, description, location, and website
3. Add your job title, department, and LinkedIn
4. Click **Save Profile**

### Create a Job
1. Go to **Jobs** from the sidebar
2. Click **Create Job**
3. Fill in title, description, location, employment/workplace type
4. Set experience and salary ranges
5. Add required skills
6. Optionally use **AI Generate** to draft a description
7. Click **Save as Draft** or **Publish**

### Manage Jobs
1. Go to **Jobs** to see all your listings
2. Filter by status (Draft, Published, Closed)
3. Click on a job to view/edit details
4. **Publish** draft jobs or **Close** active ones
5. View application count per job

### Review Applications
1. Go to **Applications** from the sidebar
2. Filter by job, status, or candidate name
3. Click on an application to review
4. View the candidate's resume (download)
5. See AI match score for the candidate
6. Update status (Shortlisted, Rejected, etc.) with notes

### Add Notes
1. On any application detail page, scroll to **Notes**
2. Click **Add Note** to add internal notes
3. Edit or delete notes as needed

### Search Candidates
1. Go to **Candidate Search** from the sidebar
2. Search by keyword, skills, location, or experience
3. View candidate profiles

### Schedule Interviews
1. On an application detail page, click **Schedule Interview**
2. Select date, time, type (Phone, Video, In-Person)
3. Add location/link and notes
4. The candidate will be notified

### Manage Interviews
1. Go to **Interviews** from the sidebar
2. View all scheduled interviews
3. Update interview details, mark as completed, or cancel

### Analytics
1. Go to **Analytics** from the sidebar
2. View recruitment funnel, hiring metrics
3. See per-job application stats
4. Track application trends over time

## Admin

### Login
1. Visit the login page with admin credentials
2. You'll see the admin dashboard with platform metrics

### Dashboard
- View total users, jobs, applications, and interviews
- See recent activity and key metrics

### User Management
1. Go to **Users** from the sidebar
2. Search users by name, email, or role
3. **Enable/Disable** user accounts
4. **Change user roles** (Candidate ↔ Recruiter ↔ Admin)
5. Click on a user to see full details

### Job Moderation
1. Go to **Jobs** from the sidebar
2. View all jobs on the platform
3. Filter by status
4. **Close** or **Delete** jobs as needed
5. Click on a job for full details

### Application Oversight
1. Go to **Applications** from the sidebar
2. View all applications across the platform
3. Filter by job, status, or candidate name

### Audit Logs
1. Go to **Audit Logs** from the sidebar
2. View system audit trail
3. Filter by actor, action, or entity type

### Analytics
1. Go to **Analytics** from the sidebar
2. View platform-wide metrics:
   - User growth trends
   - Job posting stats
   - Application trends
   - Interview analytics

## General

### Navigation
- **Sidebar**: Access all features based on your role
- **Top Bar**: Notifications bell, user menu (profile, logout)
- **Mobile**: Hamburger menu opens the sidebar

### Error Handling
- Form validation errors shown inline
- API errors displayed as toast notifications
- 401 errors auto-redirect to login
- Network errors shown with retry option

### Design System
- Visit `/design-system` to view all UI components
- Consistent color scheme with Electric Indigo accent
- Responsive layout works on desktop and mobile
